# warjorn-items

This repository stores item definitions and documentation for Warjorn.

## Structure

Each item uses a folder-based structure:

- CATEGORY/ITEM_ID/ITEM_ID.json
- CATEGORY/ITEM_ID/ITEM_ID.md
